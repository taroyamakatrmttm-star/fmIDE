# Contributing

Thank you for your interest in fmIDE.

**Outside contributions are not accepted yet.** Parts of this project are open source (Apache License 2.0) and parts are proprietary (ExcelExporter) — see [LICENSING.md](LICENSING.md). Before accepting code, documentation or templates from other people, the project will put a contributor licence agreement (CLA) in place, so that contributions can be used in every edition of fmIDE. This page will say when that happens.

Until then, you are welcome to:

- use fmIDE, and build tools around the documented file formats ([docs/file-formats.md](docs/file-formats.md));
- report problems and suggest ideas by opening an issue.

How the project is built and tested is described in [README.md](README.md) and [tests/README.md](tests/README.md).
