# Simplify for inputs

Loaded when a session works on simplifying a model for some inputs (the owner's idea of 1 November 2026, `docs/simplify-brief.md`). Keep it in step with the code, as `CLAUDE.md` asks.

- **The shared module** (`src/shared/simplify.js`, Apache, names `simplify…` / `SIMPLIFY_` / `sim…`, since the apps share one scope; fmIDE now, the batch tool later; never ExcelExporter): `simplifyInputs(system, list)` (each an input rectangle; min and max put in order; `periods` as a slider's, from 0; `{ inputs, problems }`), `simplifySteps(input)` (a slider's steps, more than `SIMPLIFY_MAX_STEPS` 401 thinned to 101), `simplifyRunPlan(inputs)` (every step alone, the corners up to 10 inputs, `SIMPLIFY_RANDOM_RUNS` 200 random combinations, seeded: the same every time; at most `SIMPLIFY_MAX_RUNS`), `simplifyJob(system, inputs, opts)` (`step(ms)` in pieces, `progress`, `label`, `result`; opts `keep`, `extraRuns` — a scenario's settings as a slider's — and `shown`, a board's rectangles), `simplifyModel` (all at once), `simplifyBuild`. Runs lay numbers over the compiled IR (`n.literal`, as fmGraph's sliders) and put them back. Items: every node of the first canvas with an id, leaving out the aliases plugs make; compared per period as a number or `E:<code>`, within 1e-9 × max(1, |v|); a block instance by its outputs; a block's definition never judged (kept whole with a kept instance).
- **The copy**: what moves, with what it reads; an unmoved source a kept item reads becomes a fixed number in place (a value rectangle with `periodValues` when its numbers differ, its arrows in cut; an input unchanged; an operator or function a value rectangle "‹reader› (fixed part)"; a block output `‹instance›~out‹n›`); never a period shift, an alias or an item with an error (kept with its calculation). A fixed 0 is dropped only from a + or a − after its first input (`canDrop`). A kept × of two inputs, one a fixed −1, feeding only the second input of a two-input + or − (no socket) is folded (`folds`): the + becomes −, the × goes (its other input wired straight when it sits after the first input, else an alias of it in the ×'s place). Saved plug aliases and arrows are dropped (`auto`; fmIDE and the IR draw them again from the plugs). Canvases left empty go; the others lose `template`. Keep anyway (`keep`): an item, or a canvas, kept with its own calculation back to the rectangles it reads. **The check**: the copy at every run and at `SIMPLIFY_CHECK_RUNS` 50 fresh random runs must give the full model's numbers; a mismatch is kept with its calculation and the copy made again (three times at most); `result.rebuild(keep)` redoes the copy from the same runs, unchecked (`checked.ok` null).
- **fmIDE** (`11h-simplify.js`): File → Simplify for Inputs… (`simplifyForInputs`, ✂, File tab's App group after Make Showcase Viewer…, `ui.simplifyAdded`; blocked in practice): the window `.simplify-box` ("?" `simplify`): `.sim-input` rows (`.sim-min`, `.sim-max`, `.sim-step`, `.sim-periods`, `.sim-remove`), `.sim-pick` (the input rectangles), `.sim-use-sliders` (the boards' sliders, `simplifyFromBoards`: `graphBoards` only — never the showcase's boards, a copy from when Make Showcase Viewer… last ran (that passes its own, `simplifyForViewer`); each row named by its rectangle's own name (`simplifyInputRects(names)`, a block's input rectangle too, which the picker leaves out), else the slider's, else `#id`; their scenarios as extra runs and their rectangles as `shown`; used at once when there are any), `.sim-work` / `.sim-progress` / `.sim-stop`, `.sim-summary`, `.sim-list` (`.sim-note`, Kept anyway, `.sim-fixed-item`, `.sim-canvas` with `.sim-keep-canvas`, `.sim-item` with `.sim-keep`), `.sim-save` (downloads the copy) and `.sim-open` (`confirmDiscardChanges`, then `openSimplifiedCopy`: a new, unsaved document "‹name› (simplified)"). The copy's document (`simplifiedDocument`): the workspace with the simplified system, its boards and showcase pruned to what is left (`simplifyPruneBoards`), and `simplified` (workspace v16, `docSimplified`, `cleanDocumentSimplified` in `src/shared/fmide-files.js`), shown by `#simplifiedBanner` (`.simplified-text`, `.simplified-list` → the record's window `.simplify-record`, `.simplified-hide`).
- **The API** (`14e-actions-simplify.js`): `fm.simplifyPlan({ sliders, inputs, keep })`, `fm.simplifyForInputs({ sliders, inputs, keep, name, download, discardChanges })` (Promises; `returns: 'value'`, `macro: false`, never recorded; inputs by `rectangle` and `canvas` reference, `periods` counted from 1), `fm.simplified()`. The first parameter is a plain one (`sliders`): an action whose first parameter is JSON takes a single object as its arguments in order.
- **The inputs and their reasons** (shared `simplifyBoardInputs(file, off)`: each input a board file moves with `boards` — its sliders — and `scenarios` setting it; `off` takes its sliders and every scenario setting it out, `scenarios.left` with `because`; `simplifyBoardsWithout` the board file without them). Simplify for Inputs… tries a scenario only when every input it sets is one chosen (`simplifyBoardsFor`, `r.scenariosLeft`); Show what goes… lists the inputs (`.sim-input-why`, `.sim-input-on`; unticking works it out again, `rerun`) and the showcase keeps the unticked ones, `simplify.off`; notes `.sim-scenario-left`, `.sim-always` (`appendSimplifyNotes`).
- **Always Keep When Simplifying** (`alwaysKeepCanvas`, ⚓, the Canvas group after Next Canvas, `ui.alwaysKeepAdded`): the document's `docAlwaysKeep` (workspace v16 `simplifyAlwaysKeep`, `cleanSimplifyAlwaysKeep`), passed by `runSimplify` as `alwaysKeep` (the shared module keeps those canvases whole and lists them, `alwaysKept`); the tab's `.always-kept` mark; `fm.alwaysKeepWhenSimplifying({ canvas, on })` (not an undo step; marks the document unsaved).
- **The Excel layout**: `simplifyExcelLayout(layout, system)` (shared) cuts the document's `excelLayout` to the copy — tabs and rows of what is gone, the Inputs tab's headings for tabs gone, and the empty-row rule — for the copy (`simplifiedDocument`) and for ExcelExporter's viewer workbook (`simplifiedForViewer`).
- **In Make Showcase Viewer…** (phase 2): `simplifyForViewer(sc, onProgress)` / `simplifiedForViewer` (11h) give the viewer's model block, its showcase pruned and the workspace for ExcelExporter; `showSimplifyKeepWindow`, `simplifyWords`; `simplifyFromBoards(file)` takes the showcase's boards. The rest in `.claude/rules/viewer.md`.
