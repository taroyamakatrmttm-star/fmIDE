# fmIDE on a phone

Loaded when a session works on the phone layouts. Moved word for word from `CLAUDE.md` (12 October 2026); keep it in step with the code, as `CLAUDE.md` asks.

- **On a phone** (step 17 P2a, `21b-phone.js`, `docs/step17-phones.md`; the shared `src/shared/phone.js` / `phone.css`): `body.phone` from `isPhoneScreen()`, decided once at start (a screen keeps its size; a window resized never switches layout), unless More (☰) → Full app (`phoneSettings.fullApp`; 📱 Phone layout `#phoneLayoutBtn` back). The page built there: `#phoneTop` (the document's name, ↶ ↷), `#phonePeriods` (‹ `#phonePeriodPick` ›, hidden for one period: `body.phone-one-period`), `#phonePanel`, `#phoneCanvasBar` (`#phoneCanvasPick`), `#phoneNav` (Inputs · Watch · Canvas · More), `#phoneMenu`, the card `#phoneCardBack` / `#phoneCard`; the ribbon, tabs, zoom control, welcome card and tutorials hidden. **Inputs** (`phoneInputs`: every input rectangle by the shared rule — `isInputRectangle` — by canvas, the ones ExcelExporter's Inputs tab gathers: nothing typed included, at 0 with "No number yet" (`blank`); a formula typed left out, and as in ExcelExporter a block's Input rectangle on a canvas used as a block and a block's index): the shared `createPhoneSlider`, range half the number either way (`phoneRange`), the notch the number when the document was opened (`phoneStart`, per `currentDoc.serial`); **a change is a change to the model**: one undo step per gesture, pushed on its first change (`phoneChanging` → `pushHistory`, so the document is marked unsaved and autosaved), the text's number through `textParts` / `composeText`, or `periodValues[currentPeriod]`; "All periods by %" (`phoneAllPeriods`, `setPhoneAllPeriods`); the calculation once per frame (`phoneCalcSoon`); an input on a canvas used as a block says how many (`phoneBlockUses`). **Watch**: `phoneSettings.watch` per document (`phoneDocKey`), at most 30, kept in the `fmIDE` database's own key `fmIDE-phone` — never in the workspace or a file. **Canvas**: `#viewport` to look at, every press stopped at the viewport (capture) so nothing is edited; a tap's click opens `openPhoneCard` (its value per period, `phoneWorkedOutFrom` / `phoneFormula` in words, `phoneReadBy`, ★, the input's slider). It follows the model through `render()` and `updateDocTitle()` (`phoneRefreshSoon`, guarded by `phoneReady`; a list is rebuilt only when what it shows changes, never while a slider is held). **☰** (P2b): Open…, Open Recent…, Save, ⇪ Share the document (`sharePhoneDocument`: `documentText()` as a `.fmide` through the shared `shareFiles`, a copy — the document stays unsaved), 📈 Open fmGraph (`openFmGraph`), 📊 Make Excel (P3, `openExcelExporter`: ExcelExporter's phone screen), ⤓ Install fmIDE (`phoneInstallOffered`: the site, not installed), Help, Full app. **The install note** `#phoneInstallNote` at the top of Inputs (`phoneInstallNoteWanted`: the site — a manifest — not installed — `display-mode` or `navigator.standalone` — and `installNoteSeen` not set; an iPhone's steps, else the browser's offer `installPrompt` as `#phoneInstallNow`, else the menu's steps; Got it `#phoneInstallOk`).
